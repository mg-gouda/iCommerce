# Badge

A short label for trust, channel, promo and state on cards, tables and detail pages.

- **Consumer provides:** text (1–3 words) and, for any state, a leading icon. Status is never color alone.
- **Variants:** `ic-badge--verified` (KYC-verified vendor or company, with shield icon; the main trust signal), `ic-badge--b2b` (wholesale-only listing or company account), `ic-badge--sale` (discount %, `accent` red; the only place red appears on product tiles), default (neutral facts: MOQ, origin, unit), `ic-badge--success` / `--warning` / `--danger` (order, quote, invoice state).
- **Don't:** stack more than 2 badges on a product image; put facts like MOQ in the card body instead.
